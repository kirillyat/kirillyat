# kirillyat.ru

Личный сайт-визитка / CV. Чистая статика — без сборки и зависимостей.

## Структура

```
data/profile.json   — ЕДИНЫЙ ИСТОЧНИК опыта/образования/стека (RU/EN/FR)
scripts/build.mjs   — генератор: profile.json → CV, README, cv.json, сайт
index.html          — разметка
css/style.css       — стили (дизайн-токены в :root)
js/data.js          — текст интерфейса сайта (RU/EN/FR)
js/profile.gen.js   — СГЕНЕРИРОВАНО: опыт+стек для сайта (не править руками)
js/main.js          — рендер и интерактив
cv/                 — СГЕНЕРИРОВАНО: CV на 3 языках + PDF
cv.json             — СГЕНЕРИРОВАНО: машиночитаемое резюме
resources/          — лекции (markdown)
```

## Как править контент

Опыт, образование, навыки, языки — **только в [data/profile.json](data/profile.json)**.
После правки запусти генератор — он пересоберёт CV (×3), блок About в README,
`cv.json` и данные опыта на сайте из одного источника:

```sh
node scripts/build.mjs
```

Текст интерфейса сайта (hero, менторство, материалы, подписи) живёт в
[js/data.js](js/data.js) — это не CV-данные, а копирайт интерфейса.

> При правке любых ассетов подними версию `?v=N` в трёх ссылках `index.html`
> (защита от кэша CDN на GitHub Pages).

## Локальный запуск

```sh
python3 -m http.server 8000
# открой http://localhost:8000
```

## Деплой

Любой статический хостинг: GitHub Pages, Cloudflare Pages, Vercel, S3 + CDN —
достаточно отдать корень репозитория.

## Фишки

- Настроение: утро в парке — голубое небо, трава, вода, тёплое солнце
- Liquid glass как у Apple: плавающая стеклянная навигация с жидким
  бегунком на пружинной физике, стеклянные карточки с бликами,
  линза-курсор с преломлением (desktop)
- Интерактивное солнце в hero: тяни по дуге — вся тема страницы
  непрерывно меняется по циклу рассвет → день → закат → ночь
  (включая тёмную тему с луной и звёздами; запоминается в localStorage)
- Комета на прогресс-баре, пыльца/звёзды на canvas,
  параллакс-глубина, призрачные номера секций
- Материалы с фильтрами: лекции / семинары / статьи (будущие помечены «скоро»)
- Менторство с формой записи (собирает mailto-письмо, бэкенд не нужен)
- Языки RU/EN/FR — сегментный свитч, выбор сохраняется в localStorage
